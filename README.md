# Ehlers-Danlos Syndrome Hypermobile Type AI-Assistant

Rare diseases are often problem for physicians and patients worldwide causing multiple misdiagnosis. As a support fine-tuned large language models can be answer for both parties.

Model can provide guildelines for patients, offering help through the diagnosis and help with solutions in everyday life, in hEDS for example giving the tips for correct training and problems with sore muscles. For physicians having no prior knowledge of the disease it can be support for what the doctor should do for the patient. Model can't be used as full diagnostic tool, because human impact through the diagnostic process is important.
